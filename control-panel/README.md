# TrendRadar 控制台

本地控制台地址默认是：

```bash
http://localhost:8092
```

启动：

```bash
cd /Users/yyt/Documents/Codex/2026-05-04/https-github-com-sansan0-trendradar-f0/TrendRadar
node control-panel/server.mjs
```

功能：

- 查看当前报告
- 手动触发一次抓取
- 添加热点关键词监控
- 查看飞书、AI、推送窗口等配置状态
- 重启 TrendRadar 容器

如果按钮提示 Docker 权限失败，请在你自己的终端启动本控制台；Codex 沙盒可能无法访问 Colima 的 Docker socket。
